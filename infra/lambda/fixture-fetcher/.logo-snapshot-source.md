# Team logo snapshot source

The static team logo mappings in `team_logos.py` were captured manually from KickoffAPI v1 for the 2026 season.

- Premier League: `/api/v1/fixtures?league=39&season=2026`
- La Liga: `/api/v1/fixtures?league=140&season=2026`
- Bundesliga: `/api/v1/fixtures?league=78&season=2026`
- Ligue 1: `/api/v1/fixtures?league=61&season=2026`
- J1 League: `/api/v1/teams?league=98&season=2026`

The Lambda does not call these endpoints for logo enrichment at runtime. Provider fixture logos win when present; the static snapshot is a fallback where wired in.
